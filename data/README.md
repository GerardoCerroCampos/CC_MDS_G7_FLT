# Datos: 2015 Flight Delays and Cancellations

Fuente: Kaggle — dataset "2015 Flight Delays and Cancellations" (usuario `usdot`).
URL: https://www.kaggle.com/datasets/usdot/flight-delays

Archivos usados:
- `flights.csv`: ~5.8M vuelos domésticos de EE.UU. en 2015. Variable objetivo: `CANCELLED` (0/1).
- `airlines.csv`: tabla de referencia código IATA -> nombre de aerolínea.
- `airports.csv`: tabla de referencia código IATA -> datos del aeropuerto.

Para reproducir: descargar los 3 archivos desde el link de Kaggle y colocarlos en esta carpeta
(`data/raw`). No se versionan en este repositorio por su tamaño (ver .gitignore).
